J-BOT Rover

An open robotics platform built from the ground up using Rust, Raspberry Pi, and ESP32-S3.

Every layer of this robot is designed to be understood, engineered, and owned—from embedded firmware to autonomous navigation. This project is focused on learning, experimentation, and building a reusable robotics ecosystem.
